Rotas públicas do site — Lodout

server.py: a fábrica Flask e as ~35 rotas públicas (home, item, ranking, método, glossário, status, mudanças, feeds) agrupadas por página, e os módulos de domínio que cada uma usa.
As linhas são as dependências reais entre arquivos/grupos (vindas do AST, não inventadas). Clique num nó: sólidas = o que ele usa, pontilhadas = quem usa ele.
