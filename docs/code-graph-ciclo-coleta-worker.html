Ciclo de coleta do worker — Lodout

Como o worker (lodout/public_site/worker.py) decide o que escanear, coleta preço na Steam, grava o resultado e dorme até o próximo ciclo. Camada 6 = módulos vizinhos, tocados pelo ciclo mas que pertencem a outro subsistema (nota/score, alertas, backups...).
As linhas são as dependências reais entre arquivos (vindas do AST, não inventadas). Clique num nó: sólidas = o que ele usa, pontilhadas = quem usa ele.
