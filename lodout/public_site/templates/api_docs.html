API

A mesma lista da página inicial, em JSON.

GET /api/recommendations

Pública e sem autenticação. Aceita até 60 consultas por minuto por IP em cada processo do site; acima disso, responde HTTP 429 (muitas consultas). Só leitura: nunca consulta a Steam e usa os mesmos dados da página inicial.

Exemplo

{{ exemplo_url }}

{
  "api_version": 1,
  "ultimo_scan": {
    "categoria": "Todas as categorias",
    "ts": 1792884599.44
  },
  "candidatos": [
    {
      "name": "AK-47 | Redline (Field-Tested)",
      "name_fmt": "AK-47 | Redline (Testada em Campo)",
      "price": 50.0,
      "price_fmt": "R$ 50,00",
      "score": 72,
      "case_label": "",
      "pump_risk": {"level": "low"},
      "reasons": ["Preço 10% abaixo do típico (+12)"],
      "market_url": "https://steamcommunity.com/market/listings/730/...",
      "icon_url": "/icone/abc123.webp"
    }
  ]
}

Campos

  • score — nota de 0 a 100 (ver como a nota é calculada)
  • reasons — até 3 motivos factuais que mais somaram pontos
  • pump_risk.level — "low", "medium" ou "high"
  • icon_url — endereço no próprio site para o ícone; o valor é null quando o item não tem hash de ícone

Traz os 20 melhores itens do momento. Para filtrar ou paginar, use os parâmetros da página inicial (?categoria=, ?nota_min=, ?preco_max=, ?q=) na página HTML; a API JSON ainda não os aceita.
